# 拾帐 · 技术支持

拾帐适用于 iPhone，可手动记录收支、在设备上识别支付截图，并按日历查看交易。

- **手动记账**：在首页点击“+”，填写金额、商家、日期和分类，核对后保存。点击已有账目可编辑。
- **截图记账**：在「设置 → 快捷记账」安装「Inpenso 截图记账 v4」，按说明绑定「轻点背面」。在支付金额页面运行快捷指令，识别结果会填入新增交易表单；确认后点击保存才记账，取消不会保存。首次运行遇到系统数据传递授权，可选择「始终允许」。
- **截图处理**：截图仅用于本次设备端识别，不另存原图，也不创建截图识别档案。识别文字可保存在交易备注中。
- **日历**：切换月份并点击日期查看当日明细。
- **账单导入**：在设置中选择微信、支付宝或招商银行账单入口，导入自己选取的文件。
- **备份**：在「设置 → 备份与数据管理」导出完整备份。导入会替换当前数据，建议先备份。
- **问题反馈**：请在 [GitHub Issues](https://github.com/gaojian960610/shi-zhang/issues/new) 说明 App 版本、iOS 版本和复现步骤。反馈公开可见，请勿附上原始账单或个人信息。

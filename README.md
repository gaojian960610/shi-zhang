# 拾帐 · 技术支持

拾帐适用于 iPhone，可手动记录收支、本机识别支付截图，并按日历查看交易。

- **截图识别**：选择包含商家和实付金额的截图，保存前核对识别结果。可在「设置 → 备份与数据管理 → 截图识别档案」查看原图和修正识别标注。
- **备份**：在「设置 → 备份与数据管理」导出完整备份。导入前建议先备份当前账本。
- **问题反馈**：请在 [GitHub Issues](https://github.com/gaojian960610/shi-zhang/issues/new) 说明 App 版本、iOS 版本和复现步骤。反馈是公开的，请勿附上原始账单、诊断包或包含个人信息的截图。
